# ConPaws 1.0.0 build 207 store screenshots

Captured from the release APK at `apps/native/android/app/build/outputs/apk/release/app-release.apk` in the main checkout. Android package metadata reports version `1.0.0` and version code `207`. The Pixel 10a emulator ran Android 17 at 1080 × 2160. These are direct captures with no overlays or compositing.

| File | Screen |
| --- | --- |
| `android-01-onboarding.png` | Welcome |
| `android-02-features.png` | Planning and offline features |
| `android-03-get-started.png` | Import prompt |
| `android-04-imported-schedule.png` | Imported 17-event demo calendar |
| `android-05-overlap-going.png` | Two saved, overlapping events |
| `android-06-event-actions.png` | Event details and schedule actions |

The demo calendar was imported through the app's file picker. The `conpaws-night-owl.ics` fixture was also imported for testing but is not represented in these screenshots.

Apple iPhone, iPad, and Watch screenshots for build 207 have not been captured. The Android images cannot substitute for them.
